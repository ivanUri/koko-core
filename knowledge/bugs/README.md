# Bug Knowledge

Every significant bug gets its own note here.

**Google Search:** start with [`../captcha/detection/google-search-investigation-journey.md`](../captcha/detection/google-search-investigation-journey.md) (thought → test → realize). Older `2026-06-29-google-search-*` notes are long-path / wire detail — superseded as the root-cause story.

## Naming

`YYYY-MM-DD-short-description.md`

Examples:

- `2026-06-28-recursive-hit-testing.md`
- `2026-07-03-css-transform-offset.md`
- `2026-07-11-pointer-events-none.md`

## What to Capture

- Symptoms
- Root cause (browser architecture, not just the patch)
- Investigation trail
- Fix and reasoning
- Lessons for future work

Use `_template.md` at the knowledge root.
